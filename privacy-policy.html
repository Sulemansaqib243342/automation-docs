Privacy Policy

Last updated: July 31, 2026

This Privacy Policy describes how Social Media Platform Automation ("the App", "we", "our") collects, uses, and protects information when you use our content scheduling tool.

1. What This App Does

Social Media Platform Automation is a personal content-scheduling tool. It automates the publishing of pre-approved content (posts, images, and videos) to social media accounts that the user has explicitly connected, including TikTok, on a schedule the user defines.

2. Information We Collect

The App accesses only the information necessary to publish content on your behalf, including:

  • OAuth access and refresh tokens issued by the connected platform (e.g., TikTok) to authorize posting
  • Basic account identifiers required to publish content (such as user ID) as provided by the platform's API
  • Content you provide for scheduling (video files, captions, titles, and scheduling times), stored temporarily in a private Google Sheet controlled by the user

3. How We Use Information

Information collected is used solely to:

  • Authenticate with the connected platform's API
  • Publish the user's own pre-approved content according to the schedule the user sets
  • Log the success or failure of each publishing attempt for the user's own review

We do not sell, rent, or share any collected data with third parties for advertising or marketing purposes.

4. Data Storage

Content and scheduling data are stored in a private Google Sheet owned and controlled by the user. Access tokens are stored securely within the user's own automation environment (n8n) and are not transmitted to or stored on any third-party server operated by us.

5. Data Retention

Data is retained only as long as needed to fulfill the scheduling and publishing purpose described above, and can be deleted at any time by the user by removing rows from the associated Google Sheet or revoking platform access.

6. Third-Party Platforms

This App integrates with TikTok's Content Posting API and other social media APIs strictly to publish content on behalf of the authorizing user. Use of these platforms is also governed by their own respective privacy policies and terms.

7. User Control

Users may revoke this App's access to their TikTok account at any time via TikTok's account settings. Doing so immediately stops any further automated publishing.

8. Contact

For questions about this Privacy Policy, please contact the developer via the contact details listed on this project's GitHub repository.
